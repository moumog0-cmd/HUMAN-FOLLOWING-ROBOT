# Human Following Robot 🤖

## Overview
This project demonstrates a human-following robot that tracks and follows a human hand using distance measurement.

## Components Used
- Arduino UNO
- Ultrasonic Sensor (HC-SR04)
- Motor Driver (L298N / L293D)
- DC Motors
- Chassis
- Battery

## Working Principle
The ultrasonic sensor detects the distance of the human hand.
- If the hand is within the threshold range → robot moves forward
- If the hand moves away → robot stops
- If the hand moves closer → robot maintains distance

## Features
- Real-time distance sensing
- Autonomous movement
- Simple logic-based control (No PID)

## Applications
- Assistive robots
- Human–robot interaction
- Robotics learning projects
